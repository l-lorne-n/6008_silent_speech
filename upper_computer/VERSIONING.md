# 版本管理与GitHub发布

作者电脑的开发目录 `upper_computer` 保留独立的本地Git历史。GitHub发布使用现有团队仓库 [l-lorne-n/6008_silent_speech](https://github.com/l-lorne-n/6008_silent_speech)，分支为 `upper_computer_v0.4.1`，程序放在仓库的 `upper_computer/` 子目录中。

该发布分支基于团队仓库的main，保留根目录旧固件，并加入v0.4.1源码快照。没有复制本机`.git`、环境、录制、模型或个人词表；下列旧标签和releases源码ZIP属于作者本机历史，不会自动出现在远程分支。克隆后进入 `upper_computer/`，按README安装并启动。

| 标签 | 含义 |
|---|---|
| `v0.1.0-stable` | 增加节律提示之前的可回退源码基线，提交 `99e31ba` |
| `v0.2.0-rhythm` | 增加实验性静息节律提示的版本 |
| `v0.3.0-lda` | 增加 LDA 数据选择、训练、评估及模型加载测试 |
| `v0.3.1-contrast` | 修复 LDA 窗口在系统深色主题下的文字可读性 |

`releases/` 中保留各版本的源码 ZIP 和 SHA256 校验清单。ZIP 包含程序、依赖清单和固件源码，不含 Python 运行环境、录制数据、训练模型和编译二进制；不是双击即运行的独立安装包。当前目录已有运行环境，继续使用 `start.cmd` 即可。

Git 管理程序、固件源码、测试、使用说明和此次节律分析脚本。`recordings/`、`models/`、`simulated/`、运行环境、测试输出及大部分历史分析产物被忽略；这不删除它们，也不构成数据或模型备份，应另行保留。

查看历史：在本目录执行 `git log --oneline --decorate`。回退前先结束保存并关闭程序，保留未来新增修改；可从相应 ZIP 解压到独立目录核对，再恢复程序源码。不要对整个采集目录执行清理或删除，也不要将旧数据目录覆盖到新数据上。独立目录运行需使用 `setup.cmd` 创建依赖环境。

v0.2.0 通过离线回放和模拟集成测试。尚未为此版本占用串口或触发新的真人录制。两版固件相同，不需要重新烧录。

v0.3.0 增加离线 LDA，已通过 30 项测试、真实录制的训练与重载一致性及 Qt 完整流程。旧标签与 ZIP 保留，新模型单独保存到 models。所有版本的固件相同。
