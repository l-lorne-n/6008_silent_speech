# 两个部署版本的模型资产

本分支包含 `mid64_temporal3` 和 `mid64_temporal3_20261027`。二者架构相同，训练数据及权重不同。路径与应用内注册表保持一致，无需下载后改名或移动。

| ID | 路径 | INT8 ONNX SHA 前16位 |
| --- | --- | --- |
| `mid64_temporal3` | `sliding_arch_sweep_20261022_125638_517426/mid64_temporal3/` | `672ca5b369cc8509dc` |
| `mid64_temporal3_20261027` | `cnn_goodone_current_20261027_214651_552433/mid64_temporal3/` | `884a42fb3d103dbc` |

每版包括最终 PyTorch 模型、FP32/INT8 ONNX、输入契约、归一化/滤波/类别/解码参数、校准说明、资源估算、训练/种子/量化选择和测试产物；实验根目录含训练时源码快照及封存清单。本分支已另外提供两版所需原始录制，见 [数据与模型对应说明](../recordings/README.md)；滤波缓存和其他架构权重不在本次提交内。根级旧对照摘要仍涉及未附带的其他实验，不能据此假定所有注册 ID 都已安装。

从仓库根目录运行 `python upper_computer/board/verify_assets.py`，按仓库相对路径检查资产及四份预构建固件。`ASSET_MANIFEST.json` 是这次发布的便携校验清单；历史训练/构建 manifest 保持原始绝对路径和内容，不要为了在新机器运行而改写它们。
