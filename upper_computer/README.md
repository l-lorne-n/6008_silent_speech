# 无声语音 sEMG 提词采集程序

当前本地版本 **v0.6.0 · 每路2 kHz / 20–500 Hz**（2026-10-16）。当前连接板已于2026-10-16烧录并校验新版固件，串口选择 **230400**（本次为COM5）。连接后INFO应显示每路2000 Hz，显示滤波自动采用20–500 Hz带通与50 Hz陷波；原始ADC值完整保存。旧固件可选115200，仍按1 kHz、20–400 Hz处理。升级步骤、HEX位置和兼容限制见 [20–500 Hz升级说明](20-500Hz升级说明.txt)。新版已编译、模拟验证并完成实机烧录和约12秒串口验证：24140对样本，CRC/缺样/设备fault均0。CH1出现5个ADC触底点，正式重采前需检查该通道信号。详情见 `releases/v0.6.0-2khz/hardware_check_20261016.json`。

主界面三行依次显示CH0活动包络、CH1活动包络、双路包络叠加，电极位置默认“喉咙脸”；模块供电另有人工填写项，默认5 V，不是程序实测电压。新2 kHz录制可用于离线LDA/CNN，不能混入旧1 kHz模型；选中2 kHz录制时LDA自动选择20–500 Hz。旧活动检测/在线识别与静息节律提示暂限1 kHz，新2 kHz输入会明确拒绝或停用。默认词表可扩展；动作协议为张嘴自然做口型、不出声。

## 活动检测与在线识别（本地实验功能）

离线LDA可选1–12段、十种特征、CH0/CH1输入；新模型v4冻结通道与特征并兼容旧v1/v2/v3单路模型。支持每批次内按轮次混合评估，见 [LDA使用说明](LDA使用说明.md)。活动模型使用独立切段特征。

主窗口右上角打开“活动检测与在线识别”。选一份开头至少5秒静息、至少3整轮的真实完整录制，点“自动检测、训练并评估”。检测器只读连续样本；阶段标记在检测后用于训练标签和评分。前80%完整轮训练、末尾轮次留出；不是旧LDA界面的随机划分。模型和报告另存到`models/activity_*`，不覆盖旧模型。

加载此窗口生成的活动切段模型后，连接真实1 kHz二进制设备，点“开始在线识别”，静息5秒，再自然做一次无声口型并放松。结果在窗口显示，不自动发送网页命令。断流、削顶会取消当前活动并重新校准；长活动被拒绝，等待放松后再检测。旧版按提词窗口训练的模型不兼容，旧离线训练入口保留。

“回放所选录制”只把原始样本交给识别器；若与训练来源相同会明确提示，不能当独立测试。当前固定检测与拒识参数只是起点；静息、吞咽/表情等非指令误触发尚未用独立数据校准，真人串口在线效果未验证。S05 11:48录制的首版连续回放表现不足以可靠控制，不能把功能接通理解为精度达标。详见`history/2026-10-10_活动检测实验版交接.md`。

## 队友首次克隆：Windows安装与启动

仓库只提供源码，第一次使用需要安装依赖；不需要创建作者的 `L:\ntu_class\6008` 目录。推荐 **Windows 10/11、64位Python 3.12**，安装Python时启用Python launcher或加入PATH。安装脚本接受64位Python 3.12–3.14，但目前实际验证环境是3.12。macOS/Linux暂未作为交付平台验证，`.cmd`脚本用于Windows。

1. 克隆团队仓库的 `upper_computer_v0.6.0` 分支，或下载该分支源码，进入含本README与start.cmd的 `upper_computer/` 文件夹。旧 `upper_computer_v0.4.1` 分支保留为历史版本。
2. 双击 **`setup.cmd`**。脚本优先使用项目内已有的独立Python，否则查找`py -3.12`和PATH中的Python，在当前目录建立`.runtime`并安装运行依赖。首次安装需要网络，完成后执行导入与依赖一致性检查。
3. 双击 **`start.cmd`**。第一次可以选“模拟演练”，不接板子也可检查界面和采集流程；模拟数据不参与真实LDA训练。
4. 真实采集需板子已烧录完整采样固件、串口驱动正常，并在界面选这台电脑实际出现的端口。**COM4只是作者电脑的默认偏好，不是强制端口。** 不要让其他串口软件同时占用它。
5. Git源码不含录制和模型。此次 [v0.6.0发布附件](https://github.com/l-lorne-n/6008_silent_speech/releases/tag/v0.6.0-2khz) 提供S011、S012、S015原始数据ZIP；解压到此目录得到 `recordings/S011` 等路径后，在LDA重新扫描。避免覆盖本机已有录制。

也可以在项目目录的PowerShell执行：

```powershell
.\setup.cmd
.\start.cmd
# 已安装后的只读环境检查，不安装软件、不连接串口：
.\setup.cmd --check
```

脚本提供`--no-pause`用于自动检查。无需激活虚拟环境，也无需修改PowerShell执行策略。升级源码后重跑`setup.cmd`可同步依赖；正在录制时先结束保存并关闭整个程序。

## 自定义词表与模型兼容（v0.4.0）

- 在“本次采集”中点击“管理词表 / 添加词”，输入词并点击添加，勾选本批要采集的词，最后保存。英文自动转小写；词不能重复，`rest` 保留给静息。每轮所有勾选词各一次，轮内随机。例如十词、每词10次，就是100个试次。
- 本机词表和勾选状态保存在 `vocabulary.json`，重启后保留；正在采集或收尾时不能改词表。每份新录制独立保存 `words`、`label_map` 和词序。已有录制、模型不随主界面词表变化；不同录制的数字标签可能不同，LDA按词语名称对齐。
- LDA根据选中的训练数据确定类别，至少两个词，不再固定四词。自动划分仍要求每个选中词在训练集至少2次、测试集至少1次；手动指定允许测试录制与训练词表不同。
- 新模型使用semg_lda_v4，保存词表、通道及特征顺序；兼容旧GUI的v1/v2/v3单路模型。早期分析脚本格式不兼容。
- 十词模型可以测试只含四词的录制，但预测仍在全部十词中选择，不会因测试标签缩小输出范围。四词模型也能测试包含新词的录制；新词会被强制判成模型已知词，并在报告中标注“未训练”，不会自动拒识。
- 结果同时显示全部准确率、已知词准确率、未训练词次数及未测试的模型类别。未训练词计入全部准确率的错误，不会被悄悄排除。输入仍须是本程序支持的真实1 kHz、含事件标记的录制。
- 添加词不会自动更新已有模型，需要采集对应数据后重新训练。CNN暂未加入，无新增依赖，无需重烧固件。

## 现在如何使用

本机独立 Python 环境已经安装好，**双击本目录的 `start.cmd` 即可启动**，不需要先安装依赖。程序运行在电脑上；Keil 仍用于给 STM32 编译和烧录，两者通过串口协议衔接。

1. 在 SerialPlot 中断开串口连接，同一端口不能同时由两个程序占用。
2. 选择 **完整采样 · 二进制v1/v2**；旧v1只支持CH0，双路需本版v2固件。旧三列文本仍可联调，队友六列文本不能作为本版完整采样输入。
3. 选择 **COM4**，点击“连接 / 检查数据”。2026-09-23 实测有效数据在 COM4（USB-SERIAL CH340）；COM3 是另一 USB 串口，当时未收到数据。拔插后端口号可能变化，请按实际情况选择。
4. 等待“数据就绪”，检查三条波形及接收速率，新固件约为 **1,000 点/秒**。
5. 填写受试者编号、电极位置（含参考电极位置）、Session 和备注。每次重新贴电极或换一天，建议换 Session。
6. 点击“开始采集”。默认每词 10 次，四词共 40 次，每轮随机顺序。初始静息 10 秒，每试次准备 1.5 秒、内部发音 2 秒、休息 2 秒，总计约 230 秒，另有保存收尾时间。
7. 可打开参与者全屏提词，按 Esc 返回操作界面。受试者无需在动作期间按键。
8. 全部完成后自动保存；也可“结束并保存”。“打开本次数据文件夹”可以直接查看结果。

**旧三列文本模式仅用于联调：它只有约 100 行/秒数据，没有设备采样序号。**2026-09-24 的 S05 新固件记录已验证完整 1 kHz 数据、连续采样序号和阶段应答；标记仍有约 20 ms 块边界粒度，不能当作屏幕实际呈现时刻的精确测量。

也可选择“模拟演练”体验界面：该模式不打开任何 COM 口，数据全部合成，单独保存到 `simulated`。模拟模式能跑通分类数据接口，并不证明真实信号能区分四个词。

## 操作行为

v0.3.0 已集成 **LDA 训练与模型测试**，入口在主界面右上角。支持选择受试者、批次和具体试次，按轮次/录制/受试者划分或手动指定训练与测试；一键训练保存模型，再加载模型测试已保存的数据。操作步骤、格式与结果解释见 [LDA使用说明](LDA使用说明.md)。本机依赖已安装，重启即可使用，无需重烧 STM32。

- **准备**：看清单词，保持放松；**动作**：保持闭唇，内部尝试发音一次；**休息**：放松。准备阶段与休息阶段在事件中分开记录。
- **当前作废 + 补录**：保留原始数据，标记该试次作废，在队尾追加新 trial_id 的补录，保存 repeat_of 关系。重复点击不会反复追加。
- **暂停**：进行中的试次标记 interrupted 并排入补录，接收和连续保存仍继续。恢复从下一个试次开始，不拼接动作前后片段。
- **结束**：当前未完成试次标为 interrupted；保留已完成试次。收尾等待约 0.75 秒以保存最终事件应答和在途数据。
- **异常**：有效数据中断、设备重启、正式记录期间采样缺口、设备故障或事件应答超时会终止批次并写错误状态。关闭正在记录的窗口时，先结束保存，再次关闭即可退出。
- **波形**：第一行显示CH0活动包络（绿色），第二行显示CH1活动包络（橙色），第三行叠加两路包络。未勾选的通道不显示；单路设备的另一行留空。完整采样/模拟模式各路独立进行20–400 Hz带通、50 Hz陷波（Q=30）及200 ms平均绝对值包络，采用连续状态的因果滤波。重新连接时清空状态，开始记录不会打断滤波。旧三列文本模式显示CH0板端包络，不对约100行/秒数据套用1 kHz滤波器。画面显示最近约5秒，保存仍包含全程原始ADC。
- **降噪与保存**：2026-09-24 加入实时 50 Hz 陷波，无需重新烧录板子；关闭并重新运行 `start.cmd` 生效。原始 ADC 和串口字节不覆盖，metadata 记录显示滤波参数。`export_trials.py` 仍导出原始片段，后续 LDA 必须显式应用预处理；不要把导出的原始片段误认为已陷波。以前的完整采样数据也可重新处理。当前仅陷波 50 Hz，未自动去除其所有谐波。

## 开始前如何看波形（2026-09-24）

三条包络图的纵轴默认均固定为0–5000 counts。点击“适配当前波形并锁定”仅调整一次：前两行按各自通道适配，第三行包含已勾选的两路；可用“手动量程”分别设置上下限。超出显示范围会提示具体行与通道，不自动缩放；显示越界不等于ADC削顶。调整量程只影响显示，不改变采样、滤波、记录或标签。

放松时先看原始信号有无突然跳变或量程端点削顶，再看滤波波形是否仍有很强的持续振荡；用包络比较“放松—内部发音一次—再放松”是否可重复增强和回落。近 1 秒滤波 RMS 是绝对数值参考，不是自动合格阈值。包络平稳不代表噪声低，强而稳定的干扰也会形成平稳包络。先放松观察约 5–10 秒，再做几次练习，比较时保持相同量程；不要为了获得平坦图形而反复缩小或放大量程。截图或单个 RMS 数值不能确认信号来源、类别可分性或硬件无异常。

若程序显示“已暂停”，则本批已开始，暂停期间仍持续保存；更新程序前应先结束并保存，再关闭重启。

## 输出文件

### 静息节律提示（v0.2.0，2026-09-24）

重启 `start.cmd` 后，在波形上方可看到“静息节律”提示。选择真实的“完整采样 · 二进制 v1”，连接后不发音、尽量不吞咽或移动，放松约 **11 秒**（半秒过渡保护，再累积连续 10 秒）。检测到重复脉冲后显示“稳定的疑似心搏节律”、约多少次/分、5–30 Hz 分支内脉冲峰峰值；幅度单位仍为 ADC counts。已暂停时也能检查。正常提词的准备、发音和短休息阶段暂停判断，不把不同休息段拼起来。

这是从喉部 sEMG 中寻找节律的实验功能，没有同步 ECG/PPG 验证。**检出不代表接线或肌电质量合格，未检出也不代表线路断开**；不会阻止开始采集，也不自动作废试次。削顶、明显基线移动、数据不连续或超过 1.5 秒无新数据时不保留旧的肯定提示。旧固件及模拟模式不启用。

计算使用独立预览分支，每秒最多分析一次；主显示仍为 20–400 Hz + 50 Hz 陷波，原始保存不受影响。metadata 保存算法配置和软件版本；本版不逐拍记录候选事件。固定纵轴及原有采集流程保留，无需重烧 STM32。

当前有效性证据是 12:34 录制静息数据回放和合成反例测试，尚未进行新的在线人体采集验证。版本与备份见 `VERSIONING.md`。

| 文件 | 内容 |
|---|---|
| samples.csv | 连续原始数据，含 host_row_idx、device_sample_idx、接收批次和电脑接收时间；旧固件的设备序号留空 |
| events.jsonl | 提示阶段、暂停/结束、软件时刻、标记发送及设备应答；真实显示时刻未硬件测量 |
| trials.jsonl | 各试次的词语、标签、完成/作废/中断状态、补录关联 |
| frames.jsonl | 接收批次记录，二进制模式另记录帧号和采样区间 |
| metadata.json | 受试者/电极/动作条件、时长、初始随机顺序、版本、采样率、错误及样本数 |
| transport.bin | 原始串口字节；文件开头包含开始保存时尚未解码的缓冲前缀 |

单位为 **ADC counts**，没有将未知模拟增益假设为已知并转换成 µV。接收时刻不是采样时刻；host_row_idx 也不是设备采样序号。旧固件 metadata 的 sampling_rate_hz=100 指串口名义数据行率，板上 ADC 名义触发率仍为 1000 Hz。

`status=recording` 的遗留元数据表示上次可能崩溃或未正常收尾，不能自动当作完整记录。数据每约 1 秒刷新文件缓冲，事件逐行刷新；这不等同于断电级持久性保证。

### 时间标记的准确含义

设备 ACK 中记录的是最近完成的 20 点块边界，量化约 20 ms，另有串口/USB传输和调度时延。文件保存了电脑发送、接收和 GUI 更新提交时刻，定期标记用于检查链路；当前版本**未实现跨时钟漂移拟合，也未标定屏幕实际亮出提示的时刻**。因此使用设备标记切出的区间是近似提示区间，不是真实肌肉动作起止。

正式批量采集前，应先验证数分钟连续序号、零故障和稳定接收速率，再用少量张嘴无声动作回放检查标签位置。必要时根据实际动作调整准备/动作/休息时长。已有录制显示组内可分类信息，但跨录制可靠性仍未解决。

## 导出试次，衔接后续 LDA

在此目录运行：

```powershell
.\.runtime\Scripts\python.exe export_trials.py "完整采样记录目录"
```

输出在cue_windows：NPZ含二维raw（采样点×通道）、channels物理顺序，以及启用的raw_ch0/raw_ch1、sample_idx、label_id、word、fs、trial_id。仅CH1保留raw_ch1身份。manifest.csv记录导出情况。

导出器要求完整采样序号、完成状态、动作开始/结束的设备 ACK、无缺点，标记往返不超过 100 ms；这是首版保守筛选阈值，不代表实际显示误差一定小于该值。拒绝旧固件的接收时间伪对齐。模拟记录必须显式加 `--allow-simulated`；目标导出目录已存在则拒绝覆盖。

LDA窗口直接读取完整录制，无需先导出。每路独立提取特征后拼接，默认每路8维；分段、统计量和通道可改，整试次/整轮划分不拆两路。导出器供独立分析使用。

## 环境与文件位置

源码在 `semg/`；电脑串口读写使用 pyserial 的独立 I/O 线程，界面使用 PySide6，绘图使用 PyQtGraph。与初始方案中 QSerialPort 的差别仅在串口库，线路和协议不变。

作者电脑的`.runtime/`是本程序的虚拟环境，底层CPython在`.python/`；队友新安装时底层Python可位于其正常安装目录，不要求存在`.python/`。本机原有Anaconda的Qt DLL冲突通过使用独立环境规避。`requirements-lock.txt`记录完整环境快照，`requirements.txt`为固定版本的运行依赖。当前测试运行时是Python 3.12.13。

重新安装时可使用 `setup.cmd`；迁移到另一台电脑时建议先安装独立的 64 位 Python 3.12，再重建运行环境，不直接搬用包含绝对解释器路径的虚拟环境。
