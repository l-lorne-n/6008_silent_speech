# LDA 训练与离线模型测试 · v0.4.0

## 可变词表与不同词表测试

主界面“管理词表 / 添加词”负责之后的采集词表。训练时以实际选中并通过检查的训练试次为准，不读取当前主界面词表；旧四词数据可以继续使用，也可以训练十词或其他至少两词的模型。每份录制按自己的词语名称解释，不把不同录制的数字label_id直接合并。

模型固定保存训练时的词表。增加采集词不会给旧模型自动增加类别，需要重新训练。新模型格式为 `semg_lda_v2`，加载器兼容原GUI的 `semg_lda_v1` 四词模型。

加载后可测试不同词表的录制：十词模型测试四词数据时仍在十词中预测；四词模型测试十词数据时，六个未训练词仍会被判成四词之一，并标注为“未训练”。这不是自动未知词检测，未训练标记来自录制的真实提示标签。

报告的“全部准确率”包括未训练词（这些必然计错）；“已知词准确率”只统计模型认识的词，若全为新词则显示不适用。混淆矩阵行含真实测试词，列为模型全部类别；未测试的模型类别也会列出。宏平均F1按全部模型类别计算，未训练词的误判会计入预测类的假阳性。因此只测试部分词时不能把指标当作完整词表表现。逐试次CSV增加 `known_to_model` 字段。

自动划分要求所有选中词在训练/测试中都有足够试次；手动指定按训练部分确定词表，允许测试中缺少一些训练词或出现新词。仍执行原来的完整性、削顶、重复试次和训练测试重叠检查。

重启 `start.cmd`，点击主界面右上角 **LDA 训练与模型测试**。本机依赖已安装。此版处理已保存的录制，暂不进行串口实时分类。

## 选择数据并训练

1. 在“训练与评估”页扫描 `recordings`。勾选受试者或录制，展开录制还可勾选具体试次。界面显示人数、组数、总次数及各词样本量；选中几个受试者，就使用几个人的数据。默认不勾选，避免把坏接线记录和出声对照自动混进来。
2. 只有一份录制时选“按轮次”，设置训练占比（默认 80%，测试 20%）；有多份录制时可选“按整组录制”，多人时可选“按受试者”。每个组完整划分，不能保证每种样本量都恰好满足百分比，实际比例以结果为准。
3. 如希望明确指定哪些批次训练、哪些批次测试，选“手动指定”，在每份录制右侧选择用途。每人的具体样本可以通过勾选试次调整；训练/测试每人每词的实际数量在结果页列出。
4. 点击“一键训练并评估”。得到准确率、宏平均 F1、混淆矩阵、实际样本量，以及模型完整保存路径。模型只用训练部分拟合，没有把测试数据再加入训练。

训练占比可选 50–90%；自动划分按随机种子复现，要求每个选中词在训练集至少两次、测试集至少一次。手动指定要求训练词至少两个、每词至少两次，测试集非空，允许测试词表不同。这些是程序运行下限，不是可靠实验所需数量的保证。数据不足时给出错误，不按准确率反复搜索“好看的”划分。

## 加载并测试

1. 点“将此模型载入测试页”，或在“加载模型与测试”页选择此前保存的 `model.json`。
2. 扫描测试数据目录，可选 `recordings` 根目录、某个受试者目录或单份录制目录，再勾选测试批次/试次。
3. 点“用模型测试所选数据”。程序沿用模型内固定滤波、特征及标准化，不重新训练。结果也会保存到新目录。

加载模型测试时会检查原始试次指纹，已训练过的试次（包括复制到其他目录的）会被拦住。若要重测训练时自动留出的部分，请只勾选 `report.json` 中的 `test` 名单，或使用另一份新录制。重测同一留出集只是复核，并不增加独立证据。

旧 `analysis/.../lda/*_model.json` 缺少本版模型格式和来源校验信息，不直接兼容；请在界面重新训练导出。只加载本版 JSON，不使用 pickle/joblib 可执行模型文件。

## 输出位置

每次运行位于唯一的 `models/train_日期_时间_随机后缀/` 或 `models/test_.../`，不覆盖旧模型。

| 文件 | 用途 |
|---|---|
| model.json | 训练生成；类别、滤波系数、八特征定义、标准化参数、LDA 系数、训练试次指纹 |
| report.json | 训练/测试名单、受试者、录制路径及哈希、排除原因、实际比例、各项指标 |
| predictions.csv | 每个测试试次的真实词、预测词及是否正确 |
| 结果说明.md | 可直接阅读的结果和混淆矩阵 |

“打开结果文件夹”可定位文件，模型路径也可以直接复制。模型目录和受试者数据均不提交到 Git，不会上传；应单独备份。

## 数据与评估边界

仅支持本程序保存的完整录制目录，至少包含 `metadata.json`、`samples.csv`、`events.jsonl`、`trials.jsonl`，不是任意孤立 CSV。模拟数据、旧 100 Hz 联调数据和仍在采集的目录不参与；已作废或中断试次不参与。采样缺口、阶段标记缺失、准备期太短、重叠区间和 ADC 削顶会报错或列入排除名单。仍须人工检查接触、动作条件和信号质量；标签是提示标签，没有自动验证操作者是否准确执行。

同批次内部测试不等于跨批次或跨人效果。按轮次时，一轮四词整体进训练或测试，不把同一试次的窗口拆开；手动取消某些试次后仍按剩余试次所属的整轮划分。更严格的比较应按整份录制或按人留出。一个人的不同批次属于跨批次，不是跨人。

沿用原来的八个特征：动作两端各裁去150 ms，均分四段，各计算 log RMS 和 log 平均绝对一阶差分。每试次独立因果滤波，用至少1秒准备期预热；StandardScaler 仅拟合训练集；LDA 使用 lsqr 和自动收缩。[scikit-learn 的 LDA 说明](https://scikit-learn.org/stable/modules/lda_qda.html)

滤波可选20–400 Hz带通加50 Hz，或加50/100/200 Hz陷波；分类滤波选择不改变采集主窗口的显示。测试固定沿用模型方案。反复查看测试分数后挑参数，会让该测试集成为开发数据；不应再把它当最终独立成绩。

## 本机验证示例

使用 S05 `20260924_123453_5ddcee`、仅50 Hz陷波、种子20260924，按轮次80/20：32次训练、8次测试，7/8正确。样本太少且来自同一录制，这个87.5%不能当作新批次或实时识别准确率，也不能与此前40次留轮次交叉验证的77.5%直接比较。

示例模型位置：`models/train_20260924_150000_94777c/model.json`。原始数据、旧模型未改变。保存/重载预测与训练器一致，特征提取和先前分析逐值一致。30项测试及真实Qt选择、后台训练、重载、测试、重叠拦截通过；原采集保存、补录、导出和节律提示回归通过。

LDA处理期间不启动新采集，正在采集时也不开始离线分析。原固件无需重新烧录。版本与回退见 `VERSIONING.md`。
