# LDA 训练与离线模型测试 · 本地更新 2026-10-10

## v0.5.0 双通道

主界面连接前选择CH0/CH1，LDA训练页另可勾选模型输入通道。每路独立滤波并提取特征，按物理通道顺序拼接；维数=通道数×分段数×每段特征数，例如2×4×2=16。默认CH0单路以兼容旧录制。两路属于同一个试次，不拆开作为独立样本。

新模型格式`semg_lda_v4`保存通道顺序，加载测试固定沿用，缺少通道或录制未启用该通道会拒绝，不补零。v1/v2/v3旧模型按CH0兼容。原始CSV双路为raw_ch0/raw_ch1，共用设备序号；新旧录制只有在模型所需通道均存在且启用时才能混合。实际肌肉位置应另行核对。详见[双通道升级说明](双通道升级说明.md)。

## 可变词表与不同词表测试

主界面“管理词表 / 添加词”负责之后的采集词表。训练时以实际选中并通过检查的训练试次为准，不读取当前主界面词表；旧四词数据可以继续使用，也可以训练十词或其他至少两词的模型。每份录制按自己的词语名称解释，不把不同录制的数字label_id直接合并。

模型固定保存训练时的词表、通道和特征配置。增加词不会给旧模型自动增加类别，需要重新训练。新格式为`semg_lda_v4`，加载器兼容v1/v2固定单路4段×2项，以及v3可变特征单路模型。

加载后可测试不同词表的录制：十词模型测试四词数据时仍在十词中预测；四词模型测试十词数据时，六个未训练词仍会被判成四词之一，并标注为“未训练”。这不是自动未知词检测，未训练标记来自录制的真实提示标签。

报告的“全部准确率”包括未训练词（这些必然计错）；“已知词准确率”只统计模型认识的词，若全为新词则显示不适用。混淆矩阵行含真实测试词，列为模型全部类别；未测试的模型类别也会列出。宏平均F1按全部模型类别计算，未训练词的误判会计入预测类的假阳性。因此只测试部分词时不能把指标当作完整词表表现。逐试次CSV增加 `known_to_model` 字段。

自动划分要求所有选中词在训练/测试中都有足够试次；手动指定按训练部分确定词表，允许测试中缺少一些训练词或出现新词。仍执行原来的完整性、削顶、重复试次和训练测试重叠检查。

重启 `start.cmd`，点击主界面右上角 **LDA 训练与模型测试**。本机依赖已安装。此入口处理已保存的录制；主界面的“活动检测与在线识别”是另一套实验流程，本页设置不改变其切段模型。

## 选择数据并训练

1. 在“训练与评估”页扫描 `recordings`。勾选受试者或录制，展开录制还可勾选具体试次。界面显示人数、组数、总次数及各词样本量；选中几个受试者，就使用几个人的数据。默认不勾选，避免把坏接线记录和出声对照自动混进来。
2. 根据评估目标选划分方式，设置训练占比（默认80%，测试20%）。若希望每个人的每个批次都一部分训练、一部分测试，选“每批次内按轮次划分（多人混合）”；若评估新批次选“按整组录制”，评估新人选“按受试者”。具体区别见下表。
3. 如希望明确指定哪些批次训练、哪些批次测试，选“手动指定”，在每份录制右侧选择用途。每人的具体样本可以通过勾选试次调整；训练/测试每人每词的实际数量在结果页列出。
4. 设置动作分段数（1–12），从六项特征中至少勾选一项。默认仍是4段×2项=8维；例如6段选四项为24维，六项全选为36维。随后点击“一键训练并评估”。得到准确率、宏平均 F1、混淆矩阵、实际样本量，以及模型完整保存路径。模型只用训练部分拟合，没有把测试数据再加入训练。

| 划分方式 | 多人、多批次时的行为 |
|---|---|
| 按轮次统一抽取（原选项） | 汇总所有批次的轮次后统一抽取测试轮次；可以混合训练，但不保证每个人、每批次在两边都有数据 |
| 每批次内按轮次划分（多人混合） | 每个有效录制分别留出整轮，其余合并训练同一个模型，所有留出试次汇总测试 |
| 按整组录制（跨批次） | 同一录制只进入一边；同一个人可能两边都有 |
| 按受试者（跨人） | 同一个人的全部录制只进入一边，衡量对未参与训练的人的表现 |

新混合方式要求每个有效批次至少有两个轮次；不足会明确报错，不自动把该批次全部分到一边。训练比例按轮次数取整，例如每批10轮、80%就是8轮训练、2轮测试。手动取消试次或完整性检查排除试次后，一轮中可能缺词，因此只保证有效批次两边都有数据，不保证每批次每个词均覆盖；全部训练/测试合计仍须满足每词数量检查。完全没有有效试次的录制不参与，排除原因保留在报告中。

结果保留总体准确率、宏平均F1、混淆矩阵，并增加每个人、每个录制的训练/测试数量和测试准确率，以及“受试者平均准确率”。总体准确率为全部正确次数除以全部测试次数；受试者平均准确率对有测试数据的各人准确率等权平均。两者并不相同，样本量大的人在总体准确率中权重更大。以上字段也写入`report.json`的`group_metrics`和结果说明。

训练占比可选 50–90%；自动划分按随机种子复现，要求每个选中词在训练集至少两次、测试集至少一次。手动指定要求训练词至少两个、每词至少两次，测试集非空，允许测试词表不同。这些是程序运行下限，不是可靠实验所需数量的保证。数据不足时给出错误，不按准确率反复搜索“好看的”划分。

## 加载并测试

1. 点“将此模型载入测试页”，或在“加载模型与测试”页选择此前保存的 `model.json`。
2. 扫描测试数据目录，可选 `recordings` 根目录、某个受试者目录或单份录制目录，再勾选测试批次/试次。
3. 点“用模型测试所选数据”。程序沿用模型内固定滤波、特征及标准化，不重新训练。结果也会保存到新目录。

加载模型测试时会检查原始试次指纹，已训练过的试次（包括复制到其他目录的）会被拦住。若要重测训练时自动留出的部分，请只勾选 `report.json` 中的 `test` 名单，或使用另一份新录制。重测同一留出集只是复核，并不增加独立证据。

旧 `analysis/.../lda/*_model.json` 缺少本版模型格式和来源校验信息，不直接兼容；请在界面重新训练导出。只加载本版 JSON，不使用 pickle/joblib 可执行模型文件。

## 输出位置

每次运行位于唯一的 `models/train_日期_时间_随机后缀/` 或 `models/test_.../`，不覆盖旧模型。

| 文件 | 用途 |
|---|---|
| model.json | 训练生成；类别、滤波系数、分段数与特征定义、标准化参数、LDA 系数、训练试次指纹 |
| report.json | 训练/测试名单、受试者、录制路径及哈希、排除原因、实际比例、各项指标 |
| predictions.csv | 每个测试试次的真实词、预测词及是否正确 |
| 结果说明.md | 可直接阅读的结果和混淆矩阵 |

“打开结果文件夹”可定位文件，模型路径也可以直接复制。模型目录和受试者数据均不提交到 Git，不会上传；应单独备份。

## 数据与评估边界

仅支持本程序保存的完整录制目录，至少包含 `metadata.json`、`samples.csv`、`events.jsonl`、`trials.jsonl`，不是任意孤立 CSV。模拟数据、旧 100 Hz 联调数据和仍在采集的目录不参与；已作废或中断试次不参与。采样缺口、阶段标记缺失、准备期太短、重叠区间和 ADC 削顶会报错或列入排除名单。仍须人工检查接触、动作条件和信号质量；标签是提示标签，没有自动验证操作者是否准确执行。

同批次内部测试不等于跨批次或跨人效果。按轮次时，一轮全部词整体进训练或测试，不把同一试次的窗口拆开；手动取消某些试次后仍按剩余试次所属的整轮划分。更严格的比较应按整份录制或按人留出。一个人的不同批次属于跨批次，不是跨人。

动作两端各裁去150 ms，再均分所选段数；每段至少50 ms，裁剪后的总动作至少400 ms，过短试次会列入排除原因。每试次独立因果滤波，用至少1秒准备期预热；StandardScaler 仅拟合训练集；LDA 使用 lsqr 和自动收缩。[scikit-learn 的 LDA 说明](https://scikit-learn.org/stable/modules/lda_qda.html)

每段可勾选的统计量如下，三个幅度类特征使用自然对数及1e-8数值保护：

| 特征 | 含义与计算 |
|---|---|
| RMS 幅度（log） | 均方根的对数，反映幅度 |
| 平均绝对相邻差（log） | 相邻采样点差的绝对值取平均后取对数，反映变化强弱 |
| 平均绝对值 MAV（log） | 采样值绝对值取平均后取对数；与RMS可能高度相关 |
| 平均频率 MNF（Hz） | 段内去均值、Hann窗、实数FFT，20–400 Hz内按功率加权的频率均值；零功率返回0 |
| 过零次数 ZC（零阈值） | 滤波后相邻两个采样点严格异号的次数；恰为零的点不计，不取对数 |
| 斜率符号变化 SSC（零阈值） | 相邻一阶差分严格异号的次数，即局部严格峰/谷数量；平坦斜率不计，不取对数 |

ZC/SSC当前固定零阈值，不从测试数据估计阈值，也没有额外幅度门限，因此很小的噪声也可能贡献计数。定义通过特征键`zc_count_zero`和`ssc_count_zero`保存在v3模型中；将来若改变阈值或定义，应使用新配置而不能悄悄改变旧模型含义。没有因新增候选特征就默认勾选它们。

默认前两项与旧八维提取数值一致。特征按勾选项顺序、再按段顺序排列；模型保存确切定义、顺序及维数，加载测试固定沿用它们，忽略训练页当前设置。分段增加的是输入维数，不增加独立试次数；更多维度不保证更好，短段的频率估计也更粗。

分段数和统计量属于特征提取设置，并不是LDA仅有的参数。LDA另有求解器、协方差收缩、类别先验等；本界面继续固定lsqr和自动收缩，没有新增这些选项。

滤波可选20–400 Hz带通加50 Hz，或加50/100/200 Hz陷波；分类滤波选择不改变采集主窗口的显示。测试固定沿用模型方案。反复查看测试分数后挑参数，会让该测试集成为开发数据；不应再把它当最终独立成绩。

## 本机验证示例

2026-10-10：S05 `20261010_114855_a28346`，保留全部100次、仅50 Hz陷波、同一留一整轮10折对照，4段×原2项为27/100，6段×原2项为26/100，6段×最初4项（不含ZC/SSC）为30/100。每折仅训练部分拟合标准化和LDA；这不是界面默认80/20单次划分的分数，也不是连续在线准确率。该数据已被多次分析，差3次只能作探索参考，需新批次独立验证。对照脚本固定历史四项，逐次结果见 `analysis/20261010_S05_114855/feature_comparison.py`、`feature_comparison.json`。

此次61项软件测试及Qt界面训练、保存、重载、固定特征测试、空特征拦截通过。原始录制六个文件哈希前后一致。没有加入或训练CNN，活动检测模型仍使用其独立配置。

随后新增ZC/SSC与每批次混合划分：70项测试通过，包含两个受试者各两个批次联合训练/重载、整轮不拆分、短批次报错、按人数/试次数两种汇总权重，以及零点/平坦斜率计数约定。Qt六项训练/重载、混合划分选项及结果文本检查通过。本次新增功能尚未报告真实数据精度提升。

使用 S05 `20260924_123453_5ddcee`、仅50 Hz陷波、种子20260924，按轮次80/20：32次训练、8次测试，7/8正确。样本太少且来自同一录制，这个87.5%不能当作新批次或实时识别准确率，也不能与此前40次留轮次交叉验证的77.5%直接比较。

LDA处理期间不启动新采集，正在采集时也不开始离线分析。原固件无需重新烧录。版本与回退见 `VERSIONING.md`。
