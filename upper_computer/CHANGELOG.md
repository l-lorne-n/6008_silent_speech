## 0.4.0 · 2026-09-24

- 主界面增加词表管理：添加、移除、勾选本批词语，本地保存并恢复；显示动态试次数，侧栏可滚动。
- 每轮按勾选词表随机排程，新录制独立保存词表和标签映射，支持新增词的模拟采集、暂停补录和导出。
- LDA支持至少两类的可变词表，动态类别系数和混淆矩阵；新模型格式semg_lda_v2，兼容原GUI四词v1模型。
- 允许模型测试不同词表的录制，分别报告全部/已知词准确率、未训练词和未覆盖类别；未实现未知词自动拒识。
- 保留原数据完整性及训练测试重叠检查；未添加CNN或新依赖，固件不变。
- 35项pytest测试通过；Qt十词模拟采集、暂停补录、导出、十类训练及四词旧模型测试十词数据通过。原真实示例模型留出结果仍为7/8，全部原始录制和正式模型文件哈希前后一致。

## 0.3.0 · 2026-09-24

- 主界面新增 LDA 工作窗口：按受试者、录制和试次勾选数据，一键训练并显示结果。
- 支持轮次、整份录制、受试者分组及手动训练/测试用途；训练占比 50–90%，报告实际比例。
- 固定八特征、训练集标准化、收缩 LDA；保存 JSON 模型、来源校验、实际划分、混淆矩阵和逐试次预测。
- 模型加载后使用固定预处理测试新录制；检查训练试次重叠、复制数据、样本缺口、无效边界、削顶及类别数量。
- 新增 scikit-learn 1.9.1；本机 Python 3.12 环境已安装，完整依赖清单更新。
- 30 项测试通过；真实数据 Qt 训练/重载/留出测试和重叠拦截通过；原有采集保存、补录、导出及节律提示回归通过。
- 旧 v0.2.0-rhythm 保留，原始数据及固件未改变。此版为已保存录制的离线训练/推理，不包含串口实时分类。

- 23 项测试、真实静息片段 Qt 回放，以及模拟提词/作废补录/保存/导出检查通过。
