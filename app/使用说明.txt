双击本目录的 start.cmd，浏览器会打开 http://127.0.0.1:8765 。
启动后保留服务窗口；结束演示时在窗口中按 Ctrl+C 即可停止。
再次双击 start.cmd 会复用已运行的服务，不会重复启动。
优先使用项目现有 upper_computer/.runtime 中的 Python，也可使用系统 Python 3.9+。
不需要 npm、联网安装或任何第三方 Python 包。所有音乐、照片都在本机读取。

也可以直接双击 index.html 做离线预览，按钮、键盘、音乐与照片可以使用；

六、接入上位机/分类器

当前网页与现有采集、训练程序独立。没有修改 upper_computer 或固件。
交接文档所述实时 CNN/连续动作切分链路仍需在上位机完成。
不要直接把原始 ADC 二进制流发给网页；先完成切段、预处理、分类和拒识。
类别编号必须用该模型保存的 classes 顺序转换成英文词，不要使用页面按钮顺序。

请求：POST http://127.0.0.1:8765/api/command
Content-Type: application/json

示例数据（仅展示格式，0.93 不是本项目实测置信度）：
{"word":"music","confidence":0.93,"id":"session01-action0001"}

word：必填，十词之一，接受前后空格和大小写。
confidence：可选，0~1 的有限数值，不是 0~100。
id：建议填写，每次完整动作一个唯一字符串；同次动作重试沿用同一 id。
不填 id 时服务会生成。服务保留最近 512 个已发送 id 用于去重。
同一个词的两个独立动作必须使用不同 id，例如连续两次 next。
不要每个滑动窗口都直接发指令；请在上游完成动作级确认/静息拒识/防抖。

响应：{"ok":true,"subscribers":1,"id":"..."}
subscribers 为实际推送的页面连接数。0 表示没有页面接收；不会缓存后自动执行旧动作。
ok 表示格式验证/投递完成，不代表浏览器动作完成或音频播放成功。
置信度拒识、浏览器自动播放限制等结果以页面反馈为准。
页面断线后会自动重连，但不重放断线期间丢失的动作。
整个服务只监听 127.0.0.1，不接受外部网页的跨域写入。

快速接口测试：
python send_command.py music --confidence 0.93
python send_command.py start --confidence 0.93
python send_command.py photo --confidence 0.93
python send_command.py open --confidence 0.93

这些命令是接口联调示例，传入的置信度由测试者填写，不是运行模型所得。

在 Python 上位机的已确认预测回调中，可以导入本目录的 send_command：

import sys
sys.path.insert(0, r"L:\ntu_class\6008\app")
from send_command import send_command

# predicted_word 由模型自己的 classes[predicted_index] 得到。
# confidence 与 action_id 使用实际预测值、实际动作标识。
result = send_command(predicted_word, confidence, event_id=action_id)

HTTP 调用有 2 秒超时，请放在工作线程/队列，避免阻塞采集线程。
调用方应捕获网络异常；重试同一动作时沿用 action_id。
如果模型没有可信置信度，可以不传；阈值为 0% 时允许执行。
调试台阈值 >0% 后，低于阈值或缺少置信度的外部指令都不会执行。
不建议未经验证就把某个固定阈值称为安全阈值。

同页 JavaScript 也可以调用：
window.Quietly.send({word: 'photo', confidence: 0.93, id: 'action-001'})
或 dispatchEvent(new CustomEvent('semg-command', {detail: {word: 'photo'}}))。
可用 window.Quietly.getState() 查看当前库、选择位置、播放/大图状态。

七、真实波形接口（可选）

POST http://127.0.0.1:8765/api/signal
Content-Type: application/json
数据：{"channels":[[实际CH0采样点...],[实际CH1采样点...]],"sample_rate":2000}

支持 1~2 个通道，每通道每批 2~500 个有限数字；建议只发送降采样后的显示数据，
每秒约 5~10 批即可，勿通过网页传输全部高频原始流。
如果做了显示降采样，sample_rate 应填写降采样后的实际采样率。
波形在调试台中自动按幅度缩放，CH0 绿色、CH1 棕色；无物理单位标定，不能据此比较绝对幅度。
3 秒没收到新波形会标注输入停止，并保留最后一帧。
网页没有随机模拟的肌电波形，没有虚构的模型准确率或硬件连接状态。
